## Функциональность

- Класс `Product` для представления товаров с атрибутами: название, описание, цена, количество
- Класс `Category` для управления категориями товаров
- Автоматический подсчет количества категорий и товаров через атрибуты класса
- Загрузка данных из JSON файлов
- Полное покрытие тестами (>75%)

#### Основные требования:
- ✅ Приватный атрибут `_products` в классе Category
- ✅ Метод `add_product()` для добавления продуктов
- ✅ Геттер `products` с форматированием "Название, X руб. Остаток: X шт."
- ✅ Приватный атрибут `_price` в классе Product
- ✅ Геттер и сеттер для `price` с проверкой на положительное значение
- ✅ Класс-метод `new_product()` для создания продукта из словаря

#### Дополнительные задания:

product = Product.new_product({
    'name': 'Смартфон',
    'description': 'Современный смартфон',

    'quantity': 50
})
