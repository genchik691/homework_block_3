# homework_block_3
# E-commerce Core

## Описание

Базовая реализация классов для e-commerce системы, включающая работу с категориями, продуктами, абстрактными классами и миксинами.

## Функциональность

### Основные классы
- **Product** - базовый класс для представления товаров с атрибутами: название, описание, цена, количество
- **Category** - класс для управления категориями товаров
- **Smartphone** - класс-наследник Product для смартфонов с дополнительными атрибутами (производительность, модель, память, цвет)
- **LawnGrass** - класс-наследник Product для газонной травы с дополнительными атрибутами (страна, срок прорастания, цвет)

### Абстрактный класс
- **BaseProduct** - абстрактный базовый класс, определяющий обязательные методы для всех продуктов:
  - `__str__` - строковое представление
  - `__add__` - сложение продуктов
  - `price` - геттер и сеттер для цены

### Миксин
- **LoggingMixin** - класс-миксин для автоматического логирования создания объектов. При создании любого продукта выводит информацию о классе и переданных параметрах.

### Магические методы
- `__str__` - для Product: "Название продукта, X руб. Остаток: X шт."
- `__str__` - для Category: "Название категории, количество продуктов: X шт."
- `__add__` - сложение продуктов с проверкой типов (только одинаковые классы)

### Дополнительные возможности
- **Order** - класс для представления заказа (дополнительное задание)
- **CategoryIterator** - итератор для перебора товаров в категории (дополнительное задание)
- Загрузка данных из JSON файлов

### Особенности реализации
- Приватные атрибуты с геттерами и сеттерами (price)
- Автоматический подсчет количества категорий и товаров через атрибуты класса
- Проверка типов при добавлении продуктов в категорию
- Проверка типов при сложении продуктов
- Полное покрытие тестами (>75%)
